# Innovation City Sets a New Standard in Web3 Security . Here’s How QuillAudits Made It Happen

## Overview
Our thorough audit identified key vulnerabilities and delivered targeted solutions, reinforcing security, improving reliability, and ensuring a robust foundation for Web3 innovation.

Innovation City’s DigitalLicense contract functions as a centrally controlled, revocable Soulbound Token (SBT) system designed to manage digital licenses with precision and control.

## Key Findings
1. License Supply Accuracy
2. Expired License Transfers
3. Start Time Handling
4. Token ID Consistency
5. Access Control Clarity
6. Event Emission Efficiency
7. Standards Compliance (ERC-5192)

## Security Improvements
1. License Supply Accuracy - Implemented a separate tracking mechanism to accurately reflect active license supply, ensuring correct reporting and system reliability
2. Expired License Transfers - Added strict expiration checks to prevent transfer or reassignment of expired licenses, preserving validity and regulatory integrity
3. Start Time Handling - Introduced validation and proper timestamp handling to ensure accurate start time recording and reliable time-based operations
4. Token ID Consistency - Aligned implementation with documentation to ensure consistent and predictable token ID behavior
5. Access Control Clarity - Updated documentation and clarified role usage to improve developer understanding and maintainability
6. Event Emission Efficiency - Removed redundant event emissions, optimizing gas usage and improving log clarity
7. Standards Compliance (ERC-5192) - Updated implementation to comply with ERC-5192, ensuring correct and expected behavior across integrations

## Audit Outcome
The Innovation City smart contracts security audit identified and addressed critical vulnerabilities, protecting user funds and ensuring platform stability.

By conducting audits and addressing identified issues, the Innovation City Team has taken a significant step towards securing its platform and safeguarding user trust.
