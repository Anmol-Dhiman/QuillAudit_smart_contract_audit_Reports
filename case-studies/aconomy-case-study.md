# QuillAudits Secures Aconomy with 37 Bug Fixes: Loan & Fee Risks Mitigated

## Overview
The audit revealed 37 issues, including significant risks that could impact financial stability, leading to crucial remediation steps.

Aconomy Protocol operates as a decentralized NFT marketplace, utilizing PiNFTs to represent real-world assets on-chain.

## Scope
- Smart Contract Audit
- Functional Testing
- Manual Code Review
- Loan & Repayment Logic Review
- NFT Security Validation
- Fee Structure Analysis

## Technologies Involved
- Solidity
- Ethereum
- ERC20
- NFT Infrastructure
- RWA
- Smart Contracts

## Key Findings
1. Denial of Service Risk in Monthly Installments
2. Lack of Support for Fee-on-Transfer Tokens
3. Unhandled Borrower Defaults
4. User-Manipulable Fee Structure
5. NFT Claim Vulnerability
6. Non-Collateralized Loan Risk

## Security Improvements
1. Improved Repayment Checks
2. Enhanced Token Handling Logic
3. Borrower Default Checks
4. Secured Fee Structure
5. Owner Verification for NFT Claims
6. Enhanced Loan Approval Protocols

## Audit Outcome
The Aconomy Protocol’s smart contracts security audit identified and addressed critical vulnerabilities, protecting user funds and ensuring platform stability.

By conducting audits and addressing identified issues, the Aconomy Protocol Team has taken a significant step towards securing its platform and safeguarding user trust.
