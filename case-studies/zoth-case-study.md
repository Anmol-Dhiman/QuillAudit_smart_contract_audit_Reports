# QuillAudits Elevates Protection, Strengthens Zoth's Onchain Financial Ecosystem

## Overview
Through a detailed 15-day audit, QuillAudits identifies and resolves critical vulnerabilities within Zoth's smart contracts, significantly improving the security and functionality of their financial ecosystem.

Zoth is a company that connects Traditional Finance (TradFi) and Onchain Finance, enabling new opportunities for enhanced liquidity and efficient tokenization mechanisms for Real World Assets (RWAs).

## Scope
- Smart Contract Audit
- Functional Testing
- Manual Code Review
- Pool & Reward Logic Review
- Locking & Withdrawal Validation
- Access Control Analysis

## Technologies Involved
- Solidity
- Polygon
- Ethereum
- ERC-721
- RWAs
- Smart Contracts

## Key Findings
1. Emergency Withdrawal Logic Flaw
2. Rate Setting Inconsistency
3. Locking Duration and End Date Validation Issues
4. Reward Calculations in Inactive Periods
5. Unrestricted Modifications of Pool Variables

## Security Improvements
1. Implemented checks to ensure penalties are applied, securing withdrawals
2. Clarified and corrected rate representation and validation rules
3. Enhanced validation to ensure logical consistency and secure operations
4. Adjusted to cease reward payouts when pool is inactive, ensuring fairness
5. Restricted modifications, aligning changes with transparency and control

## Audit Outcome
In conclusion, the Zoth audit served as a crucial step in enhancing there Smart Contracts security and operational efficiency.

The identified issues, ranging from high to low severity, were systematically addressed, reinforcing the project’s commitment to user safety and protocol stability.
