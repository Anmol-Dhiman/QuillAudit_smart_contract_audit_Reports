# How Magpie v2 Secured Reward Optimization While Safeguarding Liquidity Integrity

## Overview
Discover how QuillAudits identified and resolved critical vulnerabilities in Magpie v2, enhancing security, efficiency, and user trust in DeFi.

Magpie Protocol is built on a modular smart contract architecture that leverages the EIP-2535 Diamonds standard, enabling dynamic and flexible upgrades across its suite of functionalities.

## Scope
- Smart Contract Audit
- Functional Testing
- Manual Code Review
- Automated Security Testing
- Threat Modelling
- Cross-Chain Security Review

## Technologies Involved
- Solidity
- Ethereum
- Multichain Infrastructure
- EIP-2535 Diamonds Standard
- DeFi Protocols
- Smart Contracts

## Key Findings
1. Re-Entrancy Vulnerability
2. Inadequate External Call Validation
3. Inefficient Tokenomics Design
4. Centralized Liquidity Routing
5. High Gas Usage
6. Refund Address Vulnerability
7. Permit Front-running Risk
8. Signature Replay Vulnerability

## Security Improvements
1. Re-Entrancy Mitigation
2. External Call Safeguards
3. Refined Tokenomics
4. Decentralized Liquidity Routing
5. Gas Optimization
6. Signature Replay Protection
7. Emergency-Stop Function
8. Revert Risk Mitigation

## Audit Outcome
The Magpie Protocol’s smart contracts underwent a comprehensive security audit, which identified and mitigated critical vulnerabilities, safeguarding user funds and enhancing platform stability.

By conducting thorough audits and addressing the identified issues, the Magpie Protocol team has made significant strides in securing its platform and maintaining user trust.
