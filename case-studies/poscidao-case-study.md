# PoSciDonDAO Case Study: Smart Contract & Governance Fixes

## Overview
Explore how QuillAudits fortified PoSciDonDAO’s smart contracts and validated its governance model to ensure a secure and robust DeFi framework.

PoSciDonDAO is a pioneering Decentralized Autonomous Organization in the Decentralized Science (DeSci) movement, focused on democratizing and accelerating research in personalized medicine using blockchain and Web3 technologies.

## Scope
- Smart Contract Audit
- Governance Security Review
- Functional Testing
- Manual Code Review
- Access Control Validation
- Token Locking & Voting Logic Review

## Technologies Involved
- Solidity
- Base
- OpenZeppelin
- DAO Governance
- DeSci Infrastructure
- Smart Contracts

## Key Findings
1. Ownership Renouncement Risk in Access Control Implementation
2. Admin Role Changes Should Be Two Step
3. Missing Same-Address Check in setGovOps()
4. Missing Total Supply Validation in Lock Function

## Security Improvements
1. Improved Ownership Safeguards
2. Two-Step Admin Role Transfers
3. Address Consistency Fixes
4. Total Supply Validation

## Audit Outcome
The PosciDonDAO SciManager Smart Contract security audit identified and addressed several vulnerabilities, protecting user funds and ensuring platform stability.

By conducting audits and addressing identified issues, the PoSciDonDAO Team has taken a significant step towards securing its platform and safeguarding user trust.
